二、编译安装
----------------------------------------------------------------
# 1. 将 nginx-1.30.5.tar.gz 与 nginx_upstream_check_module-master.zip
#    上传到服务器同一目录（示例 /home/mapp），解压：
cd /home/mapp/nginx-1.30.5
tar -xzf nginx-1.30.5.tar.gz
unzip nginx_upstream_check_module-master.zip
cd nginx-1.30.5

# 2. 打健康检查补丁（使用 check_1.30.4+.patch）
patch -p1 < ../nginx_upstream_check_module-master/check_1.30.4+.patch

# 3. 编译配置（追加其他第三方模块时再加对应 --add-module）
# 注意：保持单行执行，勿拆成多行（\ 续行符后混入空格会报 invalid option " "）
./configure --prefix=/home/mapp/nginx8088 --with-http_ssl_module --with-http_stub_status_module --with-http_gzip_static_module --add-module=../nginx_upstream_check_module-master

# 4. 编译安装
make -j$(nproc) && make install

# 5. 创建运行目录（make install 不创建；run/ 存放 pid 文件，conf/vhosts/ 存放业务配置）
mkdir -p /home/mapp/nginx8088/run /home/mapp/nginx8088/conf/vhosts

# 6. 验证（输出应包含 nginx/1.30.5 及 --add-module 信息）
/home/mapp/nginx8088/sbin/nginx -V

四、systemd 服务
----------------------------------------------------------------
创建 /etc/systemd/system/nginx.service：

[Unit]
Description=nginx - high performance web server
After=network.target

[Service]
Type=forking
# nginx 装在 /home/mapp 下、仅监听 8088 非特权端口，以普通账号运行（按实际账号调整）
User=uaip
Group=uaip
PIDFile=/home/mapp/nginx8088/run/nginx.pid
ExecStartPre=/home/mapp/nginx8088/sbin/nginx -t -c /home/mapp/nginx8088/conf/nginx.conf
ExecStart=/home/mapp/nginx8088/sbin/nginx -c /home/mapp/nginx8088/conf/nginx.conf
ExecReload=/home/mapp/nginx8088/sbin/nginx -c /home/mapp/nginx8088/conf/nginx.conf -s reload
ExecStop=/home/mapp/nginx8088/sbin/nginx -c /home/mapp/nginx8088/conf/nginx.conf -s quit
Restart=on-failure
PrivateTmp=true

[Install]
WantedBy=multi-user.target

启用并设为开机自启：
systemctl daemon-reload
systemctl enable --now nginx
